# Agent Boundary Check 0.3.1

This citation release packages the source, study protocol, scoring scripts and
original calibration records together for Zenodo. The checker and research
data are the same as in 0.3.0. The archived macOS trials used the Codex sandbox
command, as documented in the study protocol.

Install and replay the reference data with Python 3.11 or later.

```sh
python -m pip install agent-boundary-check==0.3.1
agent-boundary replay
```
